# Инструменты обработки

Скрипты выполняют только механические операции и не заменяют смысловой анализ.

## `Get-SrtExcerpt.ps1`

Извлекает из SRT только блоки, пересекающие указанный диапазон времени. Используется для повторной проверки конкретной реплики вместо перечитывания полного файла.

```powershell
& '.\Get-SrtExcerpt.ps1' -Path '20.srt' -Start '00:03:00' -End '00:06:00'
```

## `Test-WikiVault.ps1`

Кратко проверяет количество файлов, непрерывность номеров сцен, дубликаты и неразрешённые вики-ссылки. Не изменяет хранилище.

```powershell
& '.\Test-WikiVault.ps1' -VaultPath 'База знаний кампании' -ThroughScene 219
```

## `Compare-VaultCopies.ps1`

Сравнивает две копии хранилища по SHA-256 и выводит только новые, изменённые и лишние файлы. Ничего не копирует и не удаляет; `.obsidian` во второй копии игнорируется.

```powershell
& '.\Compare-VaultCopies.ps1' -StagePath 'рабочая копия' -DestinationPath 'База знаний кампании'
```

Синхронизация после сравнения выполняется только по явному списку изменённых и новых файлов.
