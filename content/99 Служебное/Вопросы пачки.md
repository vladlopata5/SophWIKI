# Вопросы пачки

Пробелы памяти и расхождения в пересказах, на которые может знать ответ один из участников игр. Здесь не хранятся сюжетные тайны, которые персонажам ещё предстоит раскрыть.

Для каждого вопроса по возможности указываются предполагаемый собеседник, сцена или источник и влияние ответа на Wiki.
