# База знаний кампании 2

Отдельная Obsidian Wiki для второй кампании в общем игровом мире.

Стартовый слой перенесён из базы первой кампании выборочно. В него входят общеизвестная география, государства, календарь, языки, исторические фигуры и публичные организации. Частные сведения персонажей, результаты расследований, скрытые мотивы, тайные объекты, метаинформация мастера и теории первой группы не переносились.

Центральная страница — [[index|главная]]. Принципы отбора описаны в [[Правила общих знаний]].
