# База знаний кампании 2

Отдельная Obsidian Wiki для второй кампании в общем игровом мире.

Стартовый слой был перенесён из базы первой кампании выборочно и состоит преимущественно из общеизвестного канона. Это ограничение относится только к первоначальному переносу.

Новые сведения не фильтруются по доступности персонажам: в Wiki сохраняются также спойлеры, тайны, скрытые мотивы, метаинформация мастера и теории. Они должны быть явно помечены и отделены от установленного канона и фактического знания героев.

Центральная страница — [[index|главная]]. Правила ведения описаны в [[Правила общих знаний|правилах фиксации сведений]], а формат разбора игр — в [[Порядок обработки записей|порядке обработки записей]].
