# География мира по карте

Реестр кириллических названий и связок «государство — столица», подтверждённых Владом по карте мастера. Само размещение границ и объектов не переносится в текстовый канон: файл содержит множество автоматически созданных параметров.

Для стран заведены отдельные страницы. Для городов отдельная страница создаётся только при наличии достаточного количества сведений; остальные названия сохраняются здесь.

## Кириллические названия поселений по государствам

Названия приведены в написании карты. Известные расхождения со сложившимся написанием Вики рассматриваются как варианты: например, **Банъор / Баньёр**, **Форт: Аль'Марри / форт Аль-Мари**, **Кочкамало / Кочкамала**.

Ниже поселения сгруппированы по их текущему размещению на карте. Для столиц принадлежность государству подтверждена; для остальных городов такая группировка служит навигацией по карте и остаётся предварительной, если связь не подтверждена отдельными сведениями.
