# Кольца охранной связи Персиваля

Два кустарно изготовленных повреждённых кольца, запитанных магией и пригодных для заклинания **«Охранная связь»**. [[Яра]] продемонстрировала их работу: полученный ею урон разделился с [[Персиваль Платапус|Персивалем]].

Персиваль купил оба кольца за одну серебряную монету. Он хочет создать комплект для себя, Атласа и Эрин, но пока располагает только двумя предметами.
