# Камень послания Вренна

Камень, который [[Вренн]] передал [[Экс|Эксу]] перед расставанием в [[Поселение кобольдов Аль-Мари|поселении кобольдов Аль-Мари]]. Предназначен для поддержания связи с оставшимся на острове Вренном.

Ещё при жизни Мон-Мона связь с Вренном действительно состоялась. Через камни он передал вопрос Лолы о свёртке Джеба, а затем сообщил, что, по её сведениям, внутри находилось тифлингское оружие, использованное при убийстве капитана стражи Триплина.

Точные ограничения расстояния и частоты использования пока не установлены.
