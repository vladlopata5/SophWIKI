# Универсальный инструмент

Проект [[Сибиан|Сибиана]], над которым он работал в семейной мастерской после пожара в [[THE HOOD]]. Название подтверждено игроком при разборе [[1 - Из огня в каньон|первой игры]].

Для одного из узлов нужен материал, который больше не производят; подходящий аналог на Материальном плане трудно найти. Древние руины представляют для Сибиана интерес как возможный источник такого материала и утраченных технологий.

Название материала, точное устройство, свойства и игромеханические характеристики проекта пока неизвестны. Готового предмета у Сибиана нет. Сведения об одноимённых предметах из правил D&D к этой разработке автоматически не приписываются.

В [[2 - Ответ в тени|игре 2]] найден [[Металлический цыплёнок]] с деталями из переливающегося, в том числе зелёного, металла. **Возможная пригодность для проекта — исследовательская зацепка**, не установленное тождество искомому материалу. Механизм не разобран, материал не получен для изготовления инструмента.
